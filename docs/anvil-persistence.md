# Anvil 持久化与恢复

## 日常使用

```shell
python manage.py dev
```

或双击 `start-demo.cmd`。默认本地链仍为 `127.0.0.1:8545`、chainId=31337。启动器自动加载保存的链，不会每次重新部署合约；账户、访问令牌、任务数据库和成果继续复用。

正常关闭时，先在服务窗口按 Ctrl+C，等服务退出，再执行：

```shell
python manage.py stop-chain
```

停止前导出完整快照，确认保存成功后才停止本项目拥有的 Anvil。下一次 `dev` 或 `chain-up` 自动恢复。

需要主动保存但继续运行时：

```shell
python manage.py save-chain
```

`scripts/local_demo.py stop-chain` 和 PowerShell 停链脚本也使用相同的保存流程。服务窗口正常退出时额外保存一次，Anvil 可继续后台运行。

## 保存内容和位置

| 位置 | 内容 |
|---|---|
| `.cache/anvil/state.json` | 主动保存或停止前生成的完整快照，临时文件写入、fsync 后原子替换 |
| `.cache/anvil/state.previous.json` | 上一个有效主动快照 |
| `.cache/anvil/autosave.json` | Anvil 每 5 秒自动保存的状态 |
| `.cache/anvil/anvil.log` | 链启动日志 |
| `.cache/runtime/` | 应用数据库、任务、成果与服务日志 |
| `.cache/local-environment.json`、`local-project.json`、`local-access.txt` | 本机账户、配置和访问令牌 |
| `deployments/` | 本机部署元数据和交易日志 |

快照包含账户余额、nonce、合约代码/存储、区块、交易、回执和历史状态。恢复后仍可查询原交易和事件，并按历史区块查询状态。重启不会自动创建新账户或更换令牌。

非默认端口使用独立的 `.cache/anvil-<port>` 和进程记录，避免与默认链共用快照。Besu 入口及全面双环境隔离不属于此次改动范围。

## 异常退出与损坏快照

启动时检查主快照、自动快照和上一份快照，选择有效且区块高度最高的记录；同高度优先选择较新文件。某份文件损坏时可以使用其他有效快照，损坏文件保留。

如果已有快照全部无效，启动会停止并提示恢复备份，不会静默创建空链。端口属于其他进程、非 Anvil 或链 ID 不匹配时，也不会接管或停止它。停止前核对进程可执行文件、创建标识和监听端口，防止误停复用的 PID。

**突然断电或强制结束，只能恢复到最后一份完整快照。**正常每 5 秒自动保存一次；最近尚未保存的操作可能丢失，写入尚未完成时也可能需要回退上一份快照。它不等同于事务数据库的逐交易同步持久化保证。需要保留最新状态时，请先停止业务服务，再用 `stop-chain` 正常停链。

链状态与应用目录需一起备份；建议正常停止服务和链后备份 `.cache` 与 `deployments`。这些目录均被 Git 忽略，不上传真实密钥或运行数据。

## 以前的空链报错

如果在本功能启用前，内存模式 Anvil 已退出且没有任何快照，旧区块和合约无法重建。启动器保留旧应用记录，给出可操作的提示。需要开始新演示时执行：

```shell
python manage.py deploy
python manage.py dev
```

deploy 会备份旧运行目录、配置和令牌，然后部署新的测试合约。它会生成新的访问令牌；旧链上的任务不能迁移为新链的有效任务。不要将 deploy 当作日常启动命令。

本项目拥有的旧内存模式 Anvil 如果仍运行，首次升级会先导出当前状态，再重启为持久化模式；原合约和交易随快照保留。

## 验证

```shell
python manage.py test-integration
```

其中包含真实随机端口的停止/恢复、历史状态、异常结束、旧内存节点升级和快照损坏保护测试。完整业务恢复验证使用项目虚拟环境运行：

```shell
.cache/venv/bin/python tests/e2e/run_anvil_persistence.py
```

Windows 解释器改为 `.cache\venv\Scripts\python.exe`。该测试验证已完成任务、成果、历史回执和已领取资金保留，重复领取不重复付款，以及未完成任务在链和服务重启后继续执行。独立测试目录和随机端口不操作默认演示链。

## 空闲后首次创建任务

Anvil 按交易出块，空闲后的下一块时间可能跳到当前真实时间。创建托管任务时，开发链使用链时间和当前时间中较晚的一项计算截止时间，避免用旧区块时间创建已经过期的任务；主动推进的测试时钟仍被保留，Besu 继续使用链时间。

托管回退的本地记录保留审计证据，接口返回明确冲突提示，不再因读取不存在的链上任务返回通用 500；创建弹窗独立显示自身错误。修改后需正常退出并重启服务、刷新网页，无需重新部署或清空链。新增 5 项回归后完整 Python 测试为 70 PASS，真实浏览器正常创建、结算和超时恢复通过。
