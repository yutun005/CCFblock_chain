# 威胁模型与安全验证范围

## 参与方

| 主体 | 威胁 | 保证与剩余风险 |
|---|---|---|
| Agent | 冒签、改价、结果替换、重放、迟交 | 完整签名绑定、轮次、nonce 和时限；真实服务能力与端点身份仍由 B 核验 |
| coordinator | 错误顺序、重复请求、超预算、错误委派 | 链上预算/依赖/状态检查；可在授权范围内恶意选人或拒绝服务 |
| 未授权人 | 篡改执行者、冒领报酬、退款 | Job 权限、验证者角色、固定收款人与退款 owner |
| 授权验证者 | 对坏成果签署通过 | P0 无法阻止语义误判；SEC-30 展示真实支付及独立复算不一致 |
| 平台管理员 | 授权恶意验证者或中继 | 显式受信角色；不宣称能够防止管理员和验证者串通 |
| 数据库/Watcher | 重复提交、漏事件、崩溃 | 链上唯一结算；本地日志保存签名原始交易，重扫事件与状态对账 |
| 节点/RPC | 超时、停止、重组、伪造响应 | 确认回执及区块哈希；信任配置的 RPC；Besu 节点故障实验不等于证明任意网络攻击安全 |

## 防御边界

EIP-712 证明密钥对指定消息的认可；结果哈希绑定内容；合约约束资金。以上均不能单独证明现实业务数据真实性、私钥未泄漏或开放式 AI 输出质量。

资金安全目标由 INV-01～INV-08、SEC-01～SEC-30 的适用部分支撑。所有测试必须注明 L1/L2 合约层、L3 C 的 RPC 层，或尚待 A2A 集成的层次。

SEC-09、SEC-10 是 A/B 的实际服务注册和技能验证，不以合约模拟代替。跨层重试实验目前验证的是 C 适配器与真实链，不宣称真实恶意 A2A Agent 已运行。

## 依赖与攻击面

- OpenZeppelin 5.2.0 的 ECDSA、EIP712、SafeERC20、ReentrancyGuard、AccessControl。
- Solidity checked arithmetic；任务有限集合保证依赖和取消传播的工作量有界。
- 私钥只在本地忽略文件；实验输出保留公开账户、签名、回执与哈希。
- Besu RPC 只映射 127.0.0.1；静态节点与节点许可名单用于隔离实验。
- REST 服务身份、用户登录、TLS、真正多组织密钥治理由集成层部署设计补齐。
